Git eta bertsio-kontrola

Zer da Git?

Git bertsio-kontrolerako sistema bat da. Programa baten edo proiektu baten aldaketak gordetzeko eta kontrolatzeko erabiltzen da.

Zer da Git-Hub?

GitHub Git erabiltzen duten proiektuak Interneten gordetzeko eta beste pertsonekin partekatzeko plataforma bat da.

Oinarrizko Git komandoak

  • git init: biltegi berri bat sortzen du.
  • git status: proiektuaren egoera erakusten du.
  • git add .: aldaketa guztiak prest uzten ditu.
  • git commit -m "mezua": aldaketak gordetzen ditu.
  • git log: egindako commit-ak erakusten ditu.
  • git push: aldaketak GitHub-era igotzen ditu.
  • git pull: GitHub-eko azken aldaketak deskargatzen ditu.
  • git clone: urruneko biltegi baten kopia sortzen du.

Branch edo adarrak

Branch-ak proiektu baten bertsio desberdinak lantzeko erabiltzen dira, jatorrizko kodea aldatu gabe.

  • git branch: adarrak ikusten ditu.
  • git branch izena: adar berri bat sortzen du.
  • git checkout izena: beste adar batera joaten da.
  • git merge izena: adar bat bestearekin batzen du.

Git-en abantailak

  1. Aldaketak kontrolatzeko aukera ematen du.
  2. Aurreko bertsioetara itzultzeko aukera dago.
  3. Taldean lan egitea errazten du.
  4. Kodearen segurtasuna eta antolaketa hobetzen ditu.
